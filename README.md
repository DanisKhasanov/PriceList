# PriceList

## Описание проекта

Проект **PriceList** представляет собой веб-приложение для управления и отображения прайс-листов. Основная цель проекта — упростить процесс создания, обновления и публикации прайс-листов для различных товаров и услуг. 

Проект может быть полезен для компаний, которые хотят автоматизировать процесс работы с ценами и предоставить своим клиентам актуальную информацию о стоимости товаров.

## Основные функции

- **Управление товарами**: добавление, редактирование и удаление информации о товарах.
- **Генерация прайс-листов**: автоматическое создание прайс-листов в формате PDF для удобства распространения и использования.
- **Фильтрация и сортировка**: возможность фильтровать и сортировать товары по различным параметрам для быстрого поиска необходимой информации.
- **Интеграция с внешними системами**: обмен данными с другими системами через API для обеспечения актуальности информации о ценах.
